RouteViz {{VERSION}} for Mini Motorways  -  all-in-one package
=============================================================

RouteViz shows where the cars are going. Click a car to see its route, click a house or
destination to see every car driving to or from it, click a pin to see the car coming
for it. C clears all routes, Alt+C hides/shows them.

This package contains everything needed: the BepInEx mod loader, its settings for this
game, the support files Mini Motorways needs, and the mod. Windows, Steam version only.


INSTALL
-------
1. In Steam, right-click Mini Motorways > Manage > Browse local files.
   A folder opens that contains "Mini Motorways.exe".
2. Extract everything in this zip into that folder, so that winhttp.dll and the
   BepInEx folder sit next to "Mini Motorways.exe". Say yes if asked to replace files.
3. Start the game as usual. The first start takes a few seconds longer.

To check it worked: after starting the game once, the file
   BepInEx\LogOutput.log
should exist and contain the line "RouteViz {{VERSION}} loaded."

If you already had BepInEx installed, step 2 replaces BepInEx\config\BepInEx.cfg with
a minimal one (BepInEx re-adds the other settings with their defaults).


SETTINGS
--------
Start the game once, then edit BepInEx\config\motorways.routeviz.cfg
(route width, arrow speed, keys, sounds, ...). Restart the game to apply.


UPDATE
------
Extract the new zip over the old one. Your settings file is kept.


UNINSTALL
---------
Delete these from the game folder:
   winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt, the BepInEx folder
To turn mods off without uninstalling, open doorstop_config.ini and set enabled = false.
(Steam's "Verify integrity of game files" does NOT remove these files, because they are
not game files.)


TROUBLESHOOTING
---------------
- Nothing happens, no BepInEx folder files appear: make sure winhttp.dll is directly next
  to "Mini Motorways.exe", not in a subfolder.
- The game crashes on start: make sure you did not replace any file inside
  "Mini Motorways_Data". This package never needs to.
- The log says RouteViz loaded but clicking does nothing: check that
  BepInEx\config\BepInEx.cfg contains  HideManagerGameObject = true
- Logs: BepInEx\LogOutput.log and
  %USERPROFILE%\AppData\LocalLow\Dinosaur Polo Club\Mini Motorways\Player.log
